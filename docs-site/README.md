# Workly — Documentación (Docusaurus)

Documentación del TFG Workly generada con [Docusaurus 3](https://docusaurus.io/).

## Desarrollo local

```bash
npm install
npm start
```

La documentación arranca en `http://localhost:3000`.

## Build

```bash
npm run build
```

El build estático se genera en `build/`.

## Despliegue en Vercel

1. Importa este repositorio en [vercel.com](https://vercel.com).
2. Establece el **Root directory** a la carpeta que contiene este `package.json`.
3. Vercel detectará automáticamente la configuración de `vercel.json`.
4. Pulsa **Deploy**.

En cada push a `main`, Vercel redesplegará automáticamente.
